# 📄 Smart Document Analyzer (WIP)

Smart Document Analyzer is a powerful AI-driven tool designed to help small businesses extract key insights from their business documents like invoices, receipts, and contracts.

🚧 **Status:** Work in Progress  
🔍 **Goal:** Automate document processing and deliver actionable financial insights using LLMs and machine learning.

---

## 🔧 Features (Planned)

- 📤 Document Upload & Analysis  
- 🤖 Intelligent Information Extraction using Google Gemini  
- 🔍 Semantic Search with ML (TF-IDF + Cosine Similarity)  
- 📊 Financial Dashboards and Insights  
- 🧾 Expense Tracking across Multiple Documents  

---

## 🛠️ Tech Stack

- Google Gemini LLM  
- Python (Streamlit, scikit-learn, pandas)  
- OCR: Tesseract  
- Frontend: Streamlit  
- Data Viz: Matplotlib
